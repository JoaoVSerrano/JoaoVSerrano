## 🧭 About me

I'm a 4th-semester Intelligent Systems student at Fatec Pompéia and, since October 2026, a Full-Stack Development intern at **Rodojacto**, in the Quality, Processes and Technology department, helping build the company's new platform (web and mobile app).

Before that, I worked as an apprentice in Asset Management and Control at **Jacto**, which gave me a hands-on view of industrial processes and of how software impacts real operations. I also took part in the **Inovaskill** program (AI Support) at Fatec, preparing and structuring datasets for AI model training.

I care about clean architecture, software quality, and building systems that actually work in the real world.

## 🛠️ What I do

- 🧩 **Architecture and system design:** microservices, REST APIs, authentication (JWT, OAuth) and role-based access control (RBAC)
- 🐳 **Containerization and DevOps:** Docker, Docker Compose, CI/CD with GitHub Actions, observability with Prometheus and Grafana
- 🌐 **Full-stack applications:** Angular on the front end, Python/Flask and Java on the back end
- 📊 **Data and AI:** dataset preparation for AI, dashboards and data visualization
- 🏭 **Industry 4.0:** supervision interfaces and telemetry for industrial simulations

## 🚀 Featured projects

### 🎬 [Movie Catalog (Tom Hanks)](https://github.com/JoaoVSerrano/tomhanks)
`Python/Flask` `Angular` `Docker` `Redis` `MariaDB` `GitHub Actions`

Containerized microservices application (gateway, authentication, payments and auditing), deployed with Portainer.
- Google login, password recovery and RBAC
- Stripe subscriptions (webhooks) and Redis caching
- CI/CD pipeline (pytest, images on GHCR), observability with Prometheus/Grafana, auditing with Redis Streams, avatars stored in MinIO (S3), and OpenAPI/Swagger documentation
- Built for the Cloud Computing course

### 🚌 Student Transportation Management System (Synapse Project)
`Java` `Angular` `PostgreSQL` `Docker`

Platform for the Pompéia City Hall with QR Code validation, seat booking and real-time GPS tracking. I worked on integration and bug fixing between the Java back end and the Angular front end. The project was completed and presented, and the city hall has shown interest in deploying it.

### 🏭 Industrial and Logistics Control PWA (prototype)
`React` `Python` `JavaScript` `Railway` `Supabase`

Interface for supervising industrial simulations, with working telemetry and a chatbot, deployed on Railway with a Supabase database.

### 🌦️ [Weather Dashboard BR](https://github.com/JoaoVSerrano/Dashboard)
`Python` `Streamlit` `Data Visualization`

Interactive dashboards with weather data for Brazil.
